# Анализ и формирование требований при трансформации легаси

У нас уже есть исходная и целевая архитектура и план трансформации с описанием этапов, точек трансформации, метриками и т.д. Теперь выбираем один этап: включение наблюдаемости. И по этому этапу составляем детальную дорожную карту и cutover план. Выбрали именно этот этап, потому что он критичен для всех последующих этапов, он управляемый и обратимый, а также как раз можно измерять через слой Observability, который планируем добавить.

Работу по заданию выстроим в несколько шагов:

1. Подготовим [roadmap миграции](./migration-roadmap.md), где расписываем этапы перехода, промежуточные состояния, зависимости, риски и критерии завершения этапов.
2. Составим [cutover plan](./cutover-plan.md) для одного ключевого перехода и обозначим цель переключения, условия запуска, роли и ответственность, пошаговый сценарий, проверки после переключения и rollback-сценарий.
