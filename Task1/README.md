# Анализ и формирование требований при трансформации легаси

У нас уже есть базовая информация (некое "дано") о текущем состоянии системы, которую мы можем проанализировать. Есть информация о контексте, есть диаграмма AS-IS по заданию, а также два артефакта стенограмм интервью со стейкхолдерами.

Нужно будет это проанализировать и на основе анализа подготовить список по требованиям к системе и к трансформациям, т.е. **что требуется/должно быть**.

Работу по заданию выстроим в несколько шагов:

1. Создадим [карту стейкхолдеров](./stakeholders.md)
2. Проанализируем две стенограммы интервью со стейкхолдерами:
   - [Director of Digital Commerce](./sources/interview-business.md)
   - [Head of Customer Support](./sources/interview-support.md)
3. Подготовим [сценарии интервью](./interview-scenarios.md) с другими стейкхолдерами
4. Подготовим таблицу для [анализа интервью](./interview-analysis.md)
5. Сформируем [финальные требования](./requirements.md)
