# Анализ интервью — RetailCore

Этот документ фиксирует результаты анализа интервью со стейкхолдерами. Такой сводный документ нужен, чтобы понять:

- какие гипотезы были выдвинуты
- какие гипотезы подтвердились, а какие опроверглись
- какие GAP-ы остались открытыми
- какие новые наблюдения появились
- какие противоречия выявлены между источниками

Для каждого интервью строится таблица наблюдений. Каждое наблюдение описывается по схеме:

| Колонка | Значение |
| -- | -- |

| **Вывод** | Что это значит для архитектуры |
| **Тип** | FR / NFR / CON / ASM / GAP / RISK / PRIN |
| **Связь с GAP** | Ссылка на номер GAP. Если наблюдение порождает GAP, то указывается его ID |
